# Tables exported by [`jn_publish()`](https://njahn82.github.io/jn_analytics/reference/jn_publish.md)

All tables of the data model except `release`, which
[`jn_publish()`](https://njahn82.github.io/jn_analytics/reference/jn_publish.md)
writes together with `journal_year`.

## Usage

``` r
jn_publish_tables()
```

## Value

A character vector of table names.
