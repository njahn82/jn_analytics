# jnanalytics: Open Data About the Journal Market in Transformative Agreements

Builds and documents a tidy data model about scholarly journals covered
by transformative agreements, distinguishing hybrid from fully open
access journals. Reference tables describe journals, agreements and
dashboard portfolios once; article-level and journal-level count tables
are built in Google BigQuery from Crossref and OpenAlex, using journal
lists from the cOAlition S Journal Checker Tool and the ESAC registry.
Successor of the 'hoaddata' package.
