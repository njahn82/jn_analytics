# BigQuery fields for a jnanalytics table

BigQuery fields for a jnanalytics table

## Usage

``` r
jn_bq_fields(table)
```

## Arguments

- table:

  Table name, see
  [`jn_tables()`](https://njahn82.github.io/jn_analytics/reference/jn_tables.md).

## Value

A `bq_fields` object with types and descriptions from the schema.
