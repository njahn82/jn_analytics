# Journal ISSNs

One row per ISSN, linking print, electronic and linking ISSNs to the
journal's `issn_l`. Use it to match ISSNs from other sources to
[journals](https://njahn82.github.io/jn_analytics/reference/journals.md).

## Usage

``` r
journal_issns
```

## Format

A tibble with 2 columns:

- `issn` (string, key): Any ISSN of the journal

- `issn_l` (string): Linking ISSN it belongs to
